# Market News v2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Give `/news` (private and public) a rules-based High/Med/Low impact on every item, a Source column and single-line rows, a separate SEC/EDGAR panel, and an economic calendar (Fed events, watchlist dividends and IPOs, economic data with prior and actual) — laid out as headlines left, SEC right-top, calendar right-bottom.

**Architecture:** `news_svc` gains a pure impact scorer (stored on the item, capped for staleness at publish, re-scored from the public row for the public view), a producer-side split of the feed into `feed` (headlines) and `sec` (EDGAR kinds), and a calendar branch: pure adapters (Fed JSON, BLS/BEA ICS, FRED CSV/API/HTML, Nasdaq IPO) → last-good-per-source in `news.db` → `cache:news:calendar` / `calendar_public` / `calendar_status`, plus a FRED release-watch branch. `trade_svc` gains a scheduler that writes watchlist dividends into a shared store `news_svc` only reads — `news_svc` stays proxy-free. Design: [2026-09-26-news-v2-design.md](2026-09-26-news-v2-design.md).

**Tech Stack:** Python 3.11 stdlib (`re`, `html`, `csv`, `json`, `zoneinfo`, `sqlite3`), the existing `news_svc` fetcher/store/scaffold, `shared.config_toml`, `shared.market_calendar`, NiceGUI through `pages.ui_kit`. **No new dependency.**

## Traps (each one has a test in the task named)

| trap | where it bites | task |
|---|---|---|
| **Public-view leak.** The live Redis user reads every `cache:news:*` key; only code keeps private data off the public origin. `calendar_public` must be BUILT without `extras` dividends; `feed_public` / `sec_public` impact must be re-scored from the public row; `news_live.py` must spell no private key | T14, T16, T19 |
| **The FRED key is in every API URL** — `http_fetch` and `requests` both echo URLs into exception text | T5, T16 |
| **TZ.** Fed = Eastern, BLS = `TZID=US-Eastern`, BEA = UTC `Z`, FRED calendar HTML = **Central (unstated)**, Nasdaq/dividends = dates only. Store aware instants; display CT | T3–T6, T10 |
| **`calendar.json` starts with a UTF-8 BOM** (`json.loads` raises on it); `days` is a comma list; `time` may be `""` | T4 |
| **HTML entities** in Fed titles/locations and FRED names (`&#8217;`, `&amp;`); ICS escapes `\,` and folded lines | T3, T4, T5 |
| **Nasdaq values are STRINGS** (`"$2,530,000,000"`, `"40.00-44.00"`, `"9/30/2026"`, `null` ticker); `status.rCode` can fail under HTTP 200 | T6 |
| **Per-source User-Agent.** BLS 403s a Chrome UA; FRED resets one; Nasdaq refuses the repo UA | T1, T16 |
| **January gap** — BLS ics covers one calendar year | T12, T10 |
| **Bootstrap attribution** — a first fill must not label an old value "Actual" for a release a minute old | T12, T10 |
| **`news_svc` stays proxy-free** (no `proxy_client`, no `PROXY_URL`) | T16 |
| **Module named `calendar`** would shadow the stdlib when `app.py` runs as a script — the module is `econ_calendar.py` | T16 |
| **NaN pins the bound** — a NaN `total_value` must score 0, a NaN or `"."` observation must render `—` | T2, T12 |
| **Schwab dividend field names unverified** — tolerant parser + one prod call | T13 |
| **A list in `config/local` replaces the whole list** — keyword tiers, sources and indicators are TABLES | T1 |
