# Trading With Schwab — consolidated (aggregate) requirements

# This is the UNION of the dependencies of all four apps in the monorepo.
# Install it once into a single venv to run the whole stack:
#     pip install -r requirements.txt
#
# Each app keeps its own requirements.txt (do not delete them). Today only
# claude-driver/requirements.txt is populated; options-scanner's is empty and
# schwab-proxy / sentiment-dashboard have none, so the entries below are the
# union of claude-driver's pins plus the third-party packages the other apps
# import at runtime.
#
# De-dup rule applied: where the same package was constrained differently, the
# higher / looser constraint is kept and the dropped one is noted inline.
# Sources: P=schwab-proxy  O=options-scanner  S=sentiment-dashboard  D=claude-driver
#
# REPRODUCIBLE INSTALL: this file is the human-readable direct-dependency list.
# For a byte-identical, fully-pinned environment (all transitive deps), install
# `requirements.lock` instead (generated via `pip freeze`; refresh it after any
# dependency change). Dev/CI tooling (ruff, pre-commit, pip-audit, pytest-cov)
# lives in `requirements-dev.txt`. See docs/audits/2026-07-02-best-practices-validation.md.
